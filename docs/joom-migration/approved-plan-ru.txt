Проверка:Исходники соответствуют pristine55.2; Joom алгоритмический diff отсутствует.

G01.3 Подключение vendor и отдельный тестовый target
Настроить root patch и включить vendored crate в native workspace с явным unit/regression test target. Использовать общий native/Cargo.lock/root patch; одного membership или cargo test --manifest-path недостаточно.

G01.4 Повторная проверка и release tooling
Повторить базовые проверки после подмены registry на чистый path crate. Подготовить build-release.sh/publish-jfrog.sh, multiarch packaging/provenance; отдельно проверить upstream native-library reload.
